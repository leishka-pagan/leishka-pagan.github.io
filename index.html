01AI assurance for AML alert review

Lumen

Verifying AI-generated claims against source records.

Lumen is an assurance layer for AI-assisted anti-money-laundering review. It limits the model to a defined claim vocabulary, checks each claim with nine deterministic verifiers, and requires human review before a case can be completed. The system was built and measured with a seeded synthetic dataset.

  • 9 deterministic verifiers
  • 32 of 93 claims contradicted and caught
  • 765 passing tests (reported)

03Evidence-based security research

Sentinel

Separating confirmed observations from analyst inference.

Sentinel is a multi-agent security investigation system. It enforces read-only probing, classifies results as observed, inferred, or unconfirmed, and maps reported findings to OWASP and MITRE ATT&CK. Findings are withheld when the available evidence does not support them.

  • Read-only probes
  • Formal finding states
  • Evidence-backed reports

04Governance for agent reasoning

AXIOM

Requiring evidence and human approval before trust changes.

AXIOM uses an append-only evidence lifecycle for agent techniques. An agent cannot promote a technique to validated status without human approval. Confidence is calculated from execution results, source quality, consensus, and recency instead of being stored as editable state.

  • 134 tests
  • Append-only evidence
  • No automatic promotion
